## 保留的畫面與流程

1. 公開行程：行程名稱、區域、新增日期、預覽、使用行程，支援搜尋與區域篩選。
2. 唯讀預覽：在原頁上方顯示覆蓋層，可切換日期；網址不變，無編輯操作與私人標籤。
3. 使用行程：顯示套用成功；由「我的行程」或左側「行程」進入後，可在選單選取新增副本。
4. 我的行程：切換行程與日期，示意修改名稱、抵達時間及行程備註。
5. 發佈：顯示確認視窗，複製當下的區域、地點與行程到公開列表，移除私人標籤；後續修改原行程不會更動已發佈版本。

這份 HTML 是核准畫面的獨立保存稿，使用原 UI 的樣式與範例資料，互動以內嵌 JavaScript 示意。地圖為路線示意，所有變更只保留在本次開啟期間，重新整理即重置。側欄其餘模組僅保留視覺位置。

目前停在保存設計稿階段，尚未進入測項、IndexedDB 或後端實作。
