# 第五階段進度：5A 預覽與 5B 手動同步

第五階段已實作 5A／5B／5C，維持 DEV 限制；5C 尚待人工驗收。

## 這次改了什麼

- 資料管理的混合測試模式新增「比對本機與雲端」。
- 顯示本機獨有、雲端獨有、內容不同的資料，以及待同步操作數。
- 資料版本不同或沒有安全基準時，顯示「可能衝突」，不直接覆蓋。
- 預覽不修改本機、待同步清單或雲端資料。
- 比對途中切換帳號或本機資料改變，取消結果，要求重新比對。
- 雲端沒有同步 API 時清楚提示，不自動安裝 SQL。

## 眼見為憑

1. `npm run dev`，登入 member/admin，進入資料管理，切換「混合測試」。
2. 新增一個區域，例如「5A 本機測試」，記下待同步操作數。
3. 回資料管理，按「比對本機與雲端」。
4. **API 未安裝**：應顯示「雲端尚未安裝同步 API」，本機區域與待同步數不變。這只能驗證錯誤保護，不能代表成功雲端比對。
5. **API 已安裝**：本機新區域應顯示「僅本機有」；雲端有、本機沒有的資料應顯示「僅雲端有」。
6. 回區域畫面及原有雲端模式確認：預覽沒有搬移或覆蓋任何資料。
7. 斷網再按比對，應顯示錯誤，本機資料與待同步清單仍保留。

比對依據是「同種類、同 ID」；同名但不同 ID 不會自動合併。
內容相同也不代表可安全同步，仍需版本檢查。預覽不是同步結果或上傳憑證。

## 5B 這次改了什麼

- 新增「初始化並手動同步」／「手動雙向同步」按鈕，需確認後才執行。
- 首次下載目前帳號自己的雲端資料，保留本機待同步資料。相同 ID 發生版本衝突時整批停止，不清空本機。
- 之後先下載雲端變更，再依序上傳本機操作，最後再次下載補齊期間的變更。
- 每筆操作確認成功才移出待同步清單。失敗會保留；再次按同步可以重試。
- 上傳回應遺失時保留原上傳內容與操作 ID，先重送確認，不重複建立雲端資料。
- 同步期間的新修改不會被較舊的上傳回應蓋掉，可能留待下一次按同步。
- 下載的資料與版本／游標一起保存，不會把下載當成本機新操作。
- 相同瀏覽器不同分頁以 Web Locks 防止同時同步；不支援此能力時會拒絕同步。
- 不支援衝突自動解決；遇到衝突會顯示並保留操作，可透過 5C 明確選擇。不增加自動同步。

## 5B 人工驗收

前提：實際環境已經過獨立確認並安裝第四階段 API。2026-10-18 使用者授權後已完成安裝，詳見下方紀錄。先匯出本機與雲端備份，使用自己的測試帳號，不要拿正式資料做破壞測試。

| 操作 | 應看到的結果 |
| --- | --- |
| 雲端模式建立「雲端測試區域」，再切混合模式按初始化同步 | 回區域頁面可看到該區域；下載不增加待同步操作 |
| 混合模式建立「本機測試區域」，尚未按同步 | 切雲端模式看不到它，回混合模式仍在，待同步增加 |
| 回混合模式按手動同步並確認 | 完成後待同步減少；切雲端模式能看到相同區域 |
| 同帳號在另一個瀏覽器修改測試區域，第一個瀏覽器按同步 | 重新進入區域頁面能看到修改 |
| 刪除沒有被引用的測試區域並按同步 | 另一個瀏覽器同步後也看不到它 |
| 斷網修改本機資料，按同步 | 顯示錯誤，本機修改與待同步清單仍保留；連線後再次按同步可完成 |
| 兩瀏覽器先同步相同區域，各自改名；第二個先同步，第一個再同步 | 第一個顯示衝突，仍保留自己的名稱，雲端保留第二個名稱，不互相覆蓋 |
| 有衝突後刷新 | 衝突操作與已保存的預覽仍在，可以更新預覽後明確選擇 |

需要回到資料頁重新載入查詢結果；其他分頁不會自動刷新畫面。大批同步可能已有部分操作成功後才遇到錯誤，請看待同步／失敗／衝突數，不把錯誤解讀成雲端全部沒有改動。
回應遺失、同步中修改與 SQL 交易回滾由隔離測試覆蓋，未做實際網路斷點或多瀏覽器自動化驗證。

## 5C 人工驗收

本次沒有改動雲端 SQL。先匯出備份，使用沒有被其他資料引用的測試區域。

1. 在混合模式同步測試區域，改名為「本機版本」，先不要同步。
2. 切到雲端模式，把同一個區域改名為「雲端版本」。
3. 切回混合模式按同步，應顯示衝突且本機名稱不被覆蓋。
4. 資料管理 →「檢視／更新衝突內容」，展開該區域，確認兩邊名稱不同。
5. 選「整批保留本機版本」，確認後不會立刻上傳；再按手動同步，雲端應變成「本機版本」。
6. 重做步驟 1～4，這次選「整批採用雲端版本」，本機應採用雲端名稱，全部待同步操作被放棄。
7. 衝突預覽後若再修改任一邊，舊選擇應被拒絕，要求重新檢視。
8. 重新整理後已保存預覽仍在；離線時不能更新或確認選擇，原操作仍保留。

**重要：選擇涵蓋目前帳號全部待同步操作，包含沒有衝突的操作，不是只有畫面上的某一筆。** 為避免拆散關聯修改，目前不提供逐筆混合選擇。採雲端會放棄全部本機待同步變更；保留本機則整併為新的版本檢查操作。缺少參照、超過批次上限或有未確認的上傳結果時會拒絕，不清掉資料。
