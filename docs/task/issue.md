Q: 帳號驗證信通過 BASIC 無法使用系統 (需考慮是否需要處理, 之後想要改成 OAUTH)
A:
- 改成帳號驗證信通過直接變成 MEMBER, BASIC 可以先保留不用砍掉
- 預計改成 OAUTH 之後不用收驗證信, 只需要填入使用者暱稱即可
- 帳號註冊頁面要多一個暱稱, indexeddb 要擴充, supabase 可以直接使用已存在的 displayname 欄位
- 已註冊沒綁定 oauth 帳號 後續要可以支援綁定
